航天零件本局解锁与首次扫描修复 · 2026-10-19

原因
旧实现将解锁标记与已播放入场标记写入 PlayerPrefs，并在下一局继续读取。
因此 J 会展示以前解锁的档案，后续新局首次拾取也会被误判为已经播放过。

当前规则
五个零件在新运行时全部未发现；仅成功获得到背包后解锁对应零件。
每局每种零件的首次正常拾取播放对应的约 1.9 秒扫描入场，再进入科普阅读。
同局已看过后重开为约 0.25 秒短过渡；同局重复拾取不重复自动弹出。
反复打开空档案或调用未解锁卡片的入口不能解锁、加载模型或标记为已看过。
退出重进 Play、退出游戏后重启、重新开始场景，均重新锁定五个零件并重置首次动画。
仅当前 runtime 实例持有收集和已播放集合；旧永久标记完全不读写，其他存档和显示偏好不清除。
减少动态效果仍遵循用户设置，使用短淡入；本次未改变动画视觉、科普布局、模型、场景或导航。
Shift + F8 保留既有测试领取行为：实际入包后本局解锁，不连续弹出五个窗口，也不消耗正常拾取的首次扫描。

验证
Unity 2022.3.62f2c1，隔离产品标识 AnomalySearch.Automation / AgentRepro_EntryDressing_20261019。
gameplay-per-run.xml：61 项通过，0 失败；覆盖实际搜索转移、未搜索/满包拒绝、五个对应模型、双击竞争、短过渡、队列、暂停恢复与开箱顺序。
restart-regression.xml：2 项重点测试通过，已包含在上述 61 项中，不重复计数。
重点测试在旧解锁位与旧已播放位都为 31 时运行；两局内五种样本逐个执行完整入场，并验证未收集卡片不可访问。
另外实际执行 ExitPlayMode / EnterPlayMode，且禁用 Domain Reload，验证第二次运行仍全锁定并重新播放首次拾取。
