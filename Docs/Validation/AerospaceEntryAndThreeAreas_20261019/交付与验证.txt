回收样本入场与三处航天装饰 · 2026-10-19

正式场景
Assets/Scenes/Scene_DB/Scenezl_Final 1.unity

一、拾取入场
成功转入当前 Agent 背包后，首次发现该样本先播放约 1.9 秒的对应零件扫描入场，再展示科普面板。
收藏解锁与“已完成首次入场”分开持久化：旧存档和旧演示领取不再提前消耗首次入场。
保留旧档案与背包数据，不清空玩家进度。旧版没有独立入场记录的样本，在下一次实际拾取后补播一次。
同帧或后续的背包双击不会用档案短过渡覆盖正在播放的首次扫描。
主动提前关闭不标记为已看过；再次从背包检视该样本会重新播放。成功完成或主动跳过后记录已看过。
已看过的样本不反复自动弹窗；从档案重开采用约 0.25 秒短过渡。
开启“减少动态效果”时不显示扫描闪动/位移，但保留 0.25 秒柔和淡入。
五种零件分别使用自己的图标、名称、3D 模型与扫描范围。

二、界面与键盘
移除画面上的“领取五个飞船零件”按钮、常驻航天档案/本局数量 HUD，以及科普面板底部数量和五段进度条。
J：打开或关闭档案。背包内双击已拥有的航天零件仍可检视。
Shift + F8：静默领取测试用五个零件到当前 Agent 背包；每个 Agent 每局每种最多领取一次，空间不足可整理后再按。
以上快捷键不新增屏幕提示；输入文字时不会触发快捷键。
原有搜索节奏（第 1、4、7、10、13 个有效新箱）、普通战利品、开箱动效、拾取音效与 AI 逻辑均保持原样。

三、三处装饰
石拱路肩：追踪天线、太阳能遥测设备、发动机调查支架。
雨林搜索区：返回舱、遥测天线、双翼太阳能卫星、发动机检修支架。
奇点塔外围：卫星校验样件、返回舱、追踪天线和发动机样件。
共 12 组装饰。新建三个 Blender 模型：ReturnCapsule、OrbitalSatellite、TelemetryDish，每个有三个几何 LOD。
新模型：Assets/Art/Environment/AerospaceResearchDetails
可编辑源文件：SourceArt/AerospaceResearchDetails/AerospaceResearchDetails.blend
生成脚本：tools/art/build_research_accents.py
其他设备复用项目已有模型和材质，不新增可搜索箱子或假交互入口。
场景层级：Aerospace_AllRoutes_SetDress / Aerospace_ThreeAreas_Research_Details。
取消该子节点勾选即可只隐藏本次新增装饰。既有场景物体、植被、地形与摆放没有更改。

四、安全与验证
隔离项目测试，使用独立公司/产品标识；没有修改正式项目的 PlayerPrefs。
原始场景 4,977 个 YAML 对象均保留，逐对象比较仅原装饰根节点增加一个子引用；新场景共 5,418 个唯一对象标识。
原有 2 个 Agent、297 个碰撞体保持不变。
1,512 组导航查询（含既有不可达结果）、原 NavMesh 几何和全部路径拐点前后一致；原有完整路径为 1,308 组。
新增装饰无 Collider、Rigidbody、NavMeshObstacle、Agent、GameplayTarget，使用 Ignore Raycast 层并由 NavMeshModifier 排除烘焙。
保留路线、箱子靠近路径、交互点与敌人出生点的空隙；不修改导航数据。
60 项科普/拾取/开箱测试及 17 项场景安全测试全部通过，共 77 项。
