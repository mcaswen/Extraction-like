# 旧火箭调查景观 V2

## 方向与范围

方向：坠毁已久的火箭，基地仍在用无人设备调查。不是事故刚发生的救援现场。

正式场景仍为 `Assets/Scenes/Scene_DB/Scenezl_Final 1.unity`。本次只精修火箭景观，不扩展调查任务，不增加 AI/NPC，不改两名 Agent 的行为、资源、敌人、撤离点或地图连线。

场景中的 `Aerospace_RocketCrash_V1` 保留原来的内容，V2 启用时隐藏原版以免双重显示。新景观节点为 `Aerospace_RocketCrash_Investigation_V2`。

## 内容与资源位置

- `Assets/Art/Environment/AerospaceRocketInvestigation/Materials/`：褪色白灰箭体、旧橙色标识、锈蚀、苔藓、调查设备和状态灯材质。
- `Assets/Art/Environment/AerospaceRocketInvestigation/Meshes/`：箭体表面旧锈迹与少量苔藓、贴地旧擦痕。
- `Assets/Art/Environment/AerospaceRocketInvestigation/Prefabs/PFB_OldRocket_Investigation_V2.prefab`：完整 V2 景观组合，包括原残骸的副本和调查设备。
- 已有 Kenney CC0 模型仍位于 `Assets/Art/External/AerospaceKit_CC0/Models/Kenney_SpaceKit/`，这次复用静态天线、记录设备和漫游车；漫游车只是模型，不是新的 AI。
- 自制部分由 `Assets/Scripts/Editor/AerospaceRocketInvestigationBuilder.cs` 生成；没有新增下载素材，也没有改变第三方授权。

调查标识采用 `SITE 07 / ARCHIVED WRECK / REMOTE SURVEY` 和采样编号。保留高草的部分遮盖以表现植被重新生长；关闭副本中的残余热光，不添加火焰、浓烟或调查人员。状态灯使用发光材质，没有为新增设备增加实时灯。

## 最重要的约束：不影响行走与交互

1. 不添加 Collider、Rigidbody、NavMeshObstacle、NavMeshAgent 或玩法目标组件。
2. 所有 V2 对象采用 `Ignore Raycast` 层，不作为可点击资源或射线阻挡物；正式相机能渲染该层。
3. 根节点的 `NavMeshModifier` 设置 `Ignore From Build`，作用于全部子物体和所有 Agent 类型。注意：场景使用渲染网格收集导航，仅仅没有碰撞体不等于不参与未来烘焙。
4. 新增较大的调查设备避开正式地图连接的路径走廊，保留至少 3.5 米水平余量；同时避开群中心与资源成员的交互空间。检查使用整个设备的渲染边界，不只是轴心。
5. 不挖坑、不改 TerrainData、不移动或移除现有树木草地、不移动原残骸、不重烘焙导航。
6. 生成前后比较原导航三角形 SHA256，以及两名 Agent 的出生点到群、各群之间的路径结果和路径转角。已有不可达情况也必须保持原结果，不把旧问题计为此次修复。
7. 调用已安装 Navigation 包真实的 `NavMeshSurface.CollectSources`，确认没有 V2 网格进入导航烘焙源。

这些检查用于确认本次新增景观不改变当前行走规则，不代表全游戏所有 AI 问题均已验证。残骸没有碰撞体，角色不会因为新增调查设备卡住；请不要手动补上碰撞体或改为可搜索资源。

2026-09-18 验证：两名 Agent 的 1,512 组路径查询前后完全一致，导航网格 33,909 个顶点的三角形数据 SHA256 相同。原版其中 1,308 组查询为完整路径，其余查询保持原有结果；本次没有修复或改变旧路径的可达性。读取保存后的正式场景，再切换 V1/V2，结果也相同。10 项调查景观安全测试和 7 项地图 H 键回归测试全部通过。本机 XML 报告为 `UserSettings/TestResults/Rocket_Investigation_V2_Safety_20260918.xml`。

## 在 Unity 中对比和切回

先打开正式场景，停止 Play Mode。

- 原版：`Tools > Extraction-like > Aerospace > Wreck Comparison > Use Original V1`
- 调查版：`Tools > Extraction-like > Aerospace > Wreck Comparison > Use Investigation V2`
- 切换后按 `Cmd+S`（Windows 为 `Ctrl+S`）保存。

也可以手动勾选/取消勾选两个根节点，但应该只显示其中一个：V1 开 / V2 关是原版，V1 关 / V2 开是调查版。只取消 V2 的勾选会让残骸完全隐藏，不会自动显示 V1。

若完全撤回本次摆放：先切回 V1，再删除 V2 场景节点。不要删除 V1。资产可以保留供以后使用。

完整本机场景备份：`UserSettings/SceneBackups/Scenezl_Final 1_Before_Rocket_Investigation_V2.unity`。生成检查和实际 Unity 预览存于 `UserSettings/ScenePreviews/Aerospace_RocketInvestigation_V2/`。`UserSettings` 被 Git 忽略，不会随推送共享；V2 网格、材质、Prefab 和场景文件在 `Assets` 中，后续提交时须包括对应 `.meta`。

生成菜单为 `Tools > Extraction-like > Aerospace > Build Old Wreck Investigation V2`。已有 V2 时拒绝重复生成，避免覆盖手动调整；普通浏览与游戏运行无需使用生成工具。
