# 基地生活区与调查路线 V1

本版落实两项场景优化：食堂、宿舍外围的科研基地生活区，以及基地通往火箭、龙骨调查区的路边标识。只做景观，不扩展玩法，不处理调试胶囊体，不改天空盒、昼夜循环或植被配色。

正式场景：`Assets/Scenes/Scene_DB/Scenezl_Final 1.unity`。

## 基地生活区

独立根节点：`Aerospace_BaseLivingArea_V1`。

- 原有食堂外墙挂上“航空航天科研基地 / LF-01”“基地食堂 / 生活保障区”标牌。
- 原有宿舍外墙挂上“航空航天科研基地 / LF-02”“科研宿舍 / 驻地生活区”标牌。
- 食堂、宿舍外围各有一组维护供电柜和封闭检修设备箱，编号为 PWR-01、PWR-02。
- 宿舍外围补一个小型静态通信节点，使用项目已有 Kenney Space Kit 的 `machine_wireless.fbx`。

设备配色以旧白灰、深蓝和少量橙色为主，柜门、散热槽、把手、箱盖和锁扣有独立细节。小面积青色状态标记仅使用自发光材质，不增加真实点光源。设备柜与箱子分别贴合原有地面，不使用大平台托起。

没有新增人物、车辆 AI 或可搜刮箱子。原有床、桌椅、墙体、宝箱和设备没有移动或改材质。

## 调查路线

独立根节点：`Aerospace_InvestigationRoute_V1`。

只新增三处双面可读方向牌：基地出口侧边、火箭调查区分岔侧边、龙骨区进路侧边。统一显示“基地调查路线”，沿用火箭 `SITE-07` 与遗骸 `DB-01` 的现有编号。箭头依据每块路牌到调查区入口的大致方位绘制，只作视觉指引，不修改小地图连线或 AI 指令。

路肩另有两只封闭仪器运输箱，分别标记 SITE-07 与 DB-01。它们只是景观，不可搜索，没有资源脚本，不覆盖原有散落火箭零件。

现有 `Aerospace_Roadside_SetDress_V1` 的设备、导向灯和模型保持不变；没有再铺满道路两侧，没有设置横跨道路的门架或围栏。

- `Fonts`：用项目原有 `Assets/Font/text-c.ttf` 生成的独立静态中文 SDF 图集，没有修改地图或龙骨区共用字体。

生成脚本：`Assets/Scripts/Editor/AerospaceBaseAndRouteBuilder.cs`。普通游戏运行不需要执行生成菜单。

## 行走和交互保护

新增节点全部使用 Ignore Raycast 层，没有 Collider、Rigidbody、NavMeshObstacle、NavMeshAgent 或玩法目标。两组根节点均设置 NavMeshModifier 的 Ignore From Build，作用于所有子节点与 Agent 类型。实际检查 NavMeshSurface 的收集结果，新模型不进入导航烘焙输入。

摆放避让原有图路线、群中心、资源成员坐标、宝箱实际渲染中心、敌人出生点与两名 Agent 初始位置。按完整渲染范围检查，路线保留 3.5 米加物件半径，交互点和出生点保留 8 米加物件半径。自由站立设备还避让原有场景模型及地形树木位置；墙牌是有意安装在保留的原墙体表面。

没有重烘焙 NavMesh，没有改地形或植被，没有移动 AI、资源、敌人和撤离点。生成前后的原有序列化组件及 TerrainData 一致，1512 次导航查询、路径转角和导航三角形数据一致；原先 1308 条完整查询保持不变。这是导航与景观隔离验证，不等同于整局战斗体验测试。

## 查看与恢复

1. 打开正式场景，在 Hierarchy 搜索对应根节点；选中后按 F 聚焦。
2. 清空搜索，展开 `01_Canteen_LF01`、`02_Quarters_LF02` 或路线子组，可单独查看、移动新设备。
3. 在 Inspector 顶部取消根节点名称左侧的勾选，可隐藏这一组。两组可以独立开关；取消这两组不会隐藏原有龙骨、火箭或旧路边设备。
4. 若不满意，要撤回本次内容，可删除这两个新增根节点后保存场景。不要删除原有的 `Aerospace_Roadside_SetDress_V1`、火箭景观或龙骨景观。
5. 完整修改前备份在 `UserSettings/SceneBackups/Scenezl_Final 1_Before_BaseAndRoute_V1.unity`。完整恢复会撤销该备份之后所有场景编辑，所以通常优先使用分组开关或删除新增节点。

真实预览位于 `UserSettings/ScenePreviews/Aerospace_BaseAndRoute_V1`，包括食堂、宿舍、检修设备近景、调查路牌、夜间与原版对比。备份和预览不提交 Git。

菜单 `Tools > Extraction-like > Aerospace > Render Living Base And Survey Route V1` 用于重新生成预览，不保存临时夜间光照。生成菜单 `Build Living Base And Survey Route V1` 在检测到任一新增根节点时拒绝重建，避免覆盖你的手动调整。

本次没有提交或推送 Git。后续提交时，需包括正式场景、新脚本、整个新素材文件夹及其对应 `.meta`。
