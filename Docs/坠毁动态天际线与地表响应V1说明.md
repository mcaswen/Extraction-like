# 坠毁动态、天际线与地表响应 V1

正式场景：`Assets/Scenes/Scene_DB/Scenezl_Final 1.unity`。

独立根节点：`Aerospace_CrashAtmosphere_Skyline_V1`。这一组用于强化“坠毁已久、基地仍在调查”的画面叙事，全部以景观形式存在。

## 本次包含内容

- `01_Wreck_Dynamic_Atmosphere`：两个冷却蒸汽粒子源、六个适配卡通描边的缓慢浮动蒸汽团、间歇电火花、缓慢摆动的摄影测量扫描扇面，以及两只交替闪烁的危险信标。
- `02_Long_Range_Aerospace_Skyline`：位于主要游戏镜头远端的长程雷达和通信桅杆。两组设施使用项目已有 Kenney Space Kit CC0 模型，没有新增网络素材和授权依赖。
- `03_Impact_Ground_Response`：沿火箭撞击方向断续分布的焦土、旧油污和灰烬斑块。它们是贴地视觉网格，不修改 TerrainData，也不会形成障碍。

原先 `Aerospace_GameView_NightAndWreck_V1` 下的青色道路虚线和青色分段调查环已经同时从正式场景、Prefab、控制器引用以及网格资源中删除。仍保留橙色箭体方向标记和三座实体扫描锚点。

## 游戏视角与昼夜

所有位置与尺寸均使用正式主相机的 60° FOV、约 45° 俯视和实际跟随偏移检查。扫描光与危险信标读取 `Aerospace_DayNight_Skybox_V2` 的 160 秒昼夜相位：白天较弱，夜间增强；蒸汽和电火花在 Play Mode 中持续运行。

实际 Unity 渲染位于 `UserSettings/ScenePreviews/Aerospace_CrashAtmosphere_Skyline_V1`，包括启用前、白天、夜晚、地表响应和远景天际线画面。`UserSettings` 不提交 Git。

## 行走安全

- 根节点使用 `NavMeshModifier`，`Ignore From Build` 与 `Apply To Children` 均开启。
- 没有 Collider、Rigidbody、NavMeshObstacle、NavMeshAgent、玩法目标或新增 AI。
- 粒子碰撞关闭，危险信标只使用无阴影局部点光。
- 没有重新烘焙或改写导航网格；两名 Agent 的 1,512 组路径探针、路径拐点和导航几何哈希在启用前后保持一致。

## 对比、调整和撤回

在 Hierarchy 搜索 `Aerospace_CrashAtmosphere_Skyline_V1`：

1. 取消根节点勾选，可以对比没有本次新增氛围、天际线和地表响应的状态。
2. 删除该根节点并保存，可以从正式场景撤回本次新增组；删除不会恢复已经按要求移除的蓝色路面标记。
3. 完整生成前备份位于 `UserSettings/SceneBackups/Scenezl_Final 1_Before_CrashAtmosphere_Skyline_V1.unity`。恢复完整备份会覆盖备份之后的其他场景编辑，通常不要作为首选。

统一资源目录：`Assets/Art/Environment/AerospaceCrashAtmosphereSkylineV1`，包含 Materials、Meshes、Prefabs 和程序生成的软粒子纹理。运行控制脚本为 `Assets/Scripts/Environment/AerospaceCrashAtmosphere.cs`。

2026-09-22 验证：本组 8 项专项测试全部通过；与光照植被、基地路线、龙骨调查、旧火箭、地图隐藏恢复和原游戏视角景观组合后共 64 项全部通过。正式场景实际 Play Mode 检查确认两名 Agent 均在原 NavMesh 上，160 秒昼夜推进正常，运行时没有改写正式场景或共享天空/后处理资产。
