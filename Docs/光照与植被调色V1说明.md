# 航空航天调查区：光照与植被调色 V1

正式场景：`Assets/Scenes/Scene_DB/Scenezl_Final 1.unity`。

独立控制节点：`Aerospace_LightingAndVegetation_V1`。默认启用。本版是光照、美术调色系统，不增加游戏任务、敌人或声音。

## 本版调整

- 主方向光：白天偏中性暖白，强度 1.12；夜晚偏清晰的蓝白，强度 0.72，环境补光保留道路、建筑和目标的可见度。
- 主光启用柔和阴影，阴影强度 0.58。原有第二盏橙色方向光改为较弱的中性补光，日间 0.16、夜间 0.035，避免整片植被染黄。
- 食堂和宿舍各补一盏小范围暖色点光，不产生额外点光阴影。旧火箭已有的调查补光改为低饱和暖白，龙骨调查站原有三盏局部灯不改。
- 树冠、草地降低刺眼的黄绿，保留深浅变化；树叶高光更柔和，白色树干与棕色枝干不统一涂成绿色。风动、透明裁切和模型结构保留。
- 200–850 米的线性远景薄雾，随昼夜改变颜色；不是近身浓雾，不提供碰撞，也不参与敌人视觉判定。
- 新建独立 URP Volume：小幅对比度/饱和度调整、Neutral 色调映射、微量 Bloom。没有景深、运动模糊或暗角。游戏主相机启用后处理，原有 Volume 层遮罩保留。
- 可选场景级 Sobel 描边降噪：仅新版启用时，强度乘 0.62，法线边缘阈值至少 0.65，保留主要深度轮廓。原 URP Renderer 配置资产及其他场景保持原样。
- 天空盒 1、天空盒 2 的素材与原天空材质不变；当前完整昼夜周期为 160 秒。昼夜控制器通过可选引用调用本版光照，避免下一帧把调色灯光覆盖掉。

## 在 Unity 中查看与对比

1. 打开上面的正式场景，等待编译完成。
2. 在 Hierarchy 搜索 `Aerospace_LightingAndVegetation_V1`。
3. 选中节点，Inspector 上方名称左侧的勾选为整套开关。
4. 取消勾选：恢复本次修改前的树木材质、草地地形、主相机后处理、原灯光与雾设置；调查道具、龙骨、火箭以及你之前移动的模型不会消失。
5. 再次勾选：重新启用新版。对比时昼夜阶段不重置。
6. 也可以使用菜单 `Tools > Extraction-like > Lighting And Vegetation > Use Original - Before V1` 或 `Use V1 - Aerospace Palette`。菜单只调整当前场景，不强制打开其他文件；改完按 Cmd+S 保存。
7. 若 Scene 窗口看不到光照差异，检查窗口上方 Scene Lighting 是否开启，以及 Effects 中的 Fog 是否显示。后处理与游戏描边效果以 Game 窗口为准。

白天、黄昏、夜晚预览仍可使用原有菜单 `Tools > Extraction-like > Skybox > Preview 2`。进入 Play Mode 后天空盒 2 正常按 160 秒循环。若切换回天空盒 1，新版植被和调色开关仍可独立保留。

## 自己调整亮度和配色

在控制节点的 `Aerospace Lighting Vegetation Profile` 组件中修改：

- `Day Sun Intensity`：日间主光亮度。
- `Night Sun Intensity`：夜间主光亮度，建议小范围调整，不一下降到接近 0。
- `Day / Night Sky Ambient`、`Equator Ambient`、`Ground Ambient`：阴影区域的天空、水平与地面补光。
- `Sun Shadow Strength`：阴影深浅，默认 0.58。
- `Use Distance Haze`：远景薄雾独立开关；`Haze Start / End`：薄雾距离。
- `Sobel Intensity Scale`、`Sobel Normal Threshold`：游戏细碎描边程度；回到 1 与 0.25 接近原版。

植被材质副本在 `Assets/Art/Environment/AerospaceLightingAndVegetation_V1/Materials`。自定义 Foliage Lit 材质保留 URP Lit 的颜色、法线、透明与表面设置，底色可调；着色器只对黄绿植被像素做灰绿重映射。Synty 材质可调 `Leaf Base / Noise Colour`，建议保留三种深浅。

草地地形层副本在 `TerrainLayers`，用 URP 的地形漫反射颜色映射调色，没有改贴图文件或绘制新的地表。

后处理副本在 `Profiles/VP_Aerospace_Readable_DayNight.asset`。其中 Contrast=4、Saturation=-6、Bloom Intensity=0.10。昼夜动画只改 Volume 的私有运行副本，不写回该资产；若以后需要改变随昼夜变化的曝光值，可在控制脚本的 `ApplyPhase` 中调整。

## 素材与修改范围

统一文件夹：`Assets/Art/Environment/AerospaceLightingAndVegetation_V1`。

- `Materials`：13 份植被材质副本。
- `TreePrototypes`：6 份树木/草丛原型副本，引用原模型网格，仅替换材质。非植被的石墙、剑石等原型不改。
- `TerrainLayers`：草地、落叶地表颜色层副本。
- `Terrain`：9 份地形数据副本，合计约 23 MB。高度、洞、地表权重、所有树木及细节位置与原版完全一致。
- `Profiles`：独立后处理配置。
- `Shaders`：URP 14.0.12 Lit 派生着色器及许可证说明。调色逻辑在 `Assets/Shader/ToonOutlines/AerospaceFoliageLitInput.hlsl`。

没有新下载或生成贴图。原第三方树木、模型、材质、地形层与 TerrainData 都不覆盖；没有更改水材质、HUD 字体、地图配置、AI/怪物代码或原 URP 设置资产。

地形的渲染和 TerrainCollider 同步引用同一数据版本，但两版的几何和原型碰撞形状完全相同。没有添加、删除或移动任何树木，没有重烘焙 NavMesh 或光照。新控制节点不含网格、碰撞体或导航代理，并通过 NavMeshModifier 排除导航收集。

注意：两版地形是这次调色时的同布局快照。以后若要雕刻地形、重新种树或改地表布局，需要明确编辑哪份并同步另一版；不要把两套数据当成实时联动的同一份地形。单纯调灯、调材质颜色不需要同步布局。

## 撤回与备份

优先取消整个控制节点的勾选，即可恢复原版并保留新版供之后对比。

要删除本版，先取消勾选，确认画面恢复，再删除该控制节点并保存。对应材质副本可先保留，不要直接删除还被场景引用的资源文件夹。

完整修改前备份：`UserSettings/SceneBackups/Scenezl_Final 1_Before_LightingAndVegetation_V1.unity`。完整恢复会同时撤销备份之后的其他场景编辑，因此后续有手动修改时优先使用开关。

实景预览和验证报告：`UserSettings/ScenePreviews/Aerospace_LightingAndVegetation_V1`。

生成菜单在检测到已有控制节点时拒绝重建，避免覆盖你的调整。对比图生成菜单 `Render V1 Comparison` 不保存临时夜间光照，但会载入正式场景，请先保存自己的未完成编辑再使用。

本次不提交、不推送 Git。之后提交应包括场景、新资源与 `.meta`、新增的控制与编辑器脚本、新测试、Foliage 输入文件，以及昼夜控制器和 Sobel 渲染功能的兼容性修改。备份与预览目录保持 Git 忽略。
