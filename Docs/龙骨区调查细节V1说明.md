# 龙骨区调查细节 V1

本版以“旧遗骸正在接受基地远程调查”为方向，只补小型景观，不在龙骨区内放新的大型建筑。正式场景是 `Assets/Scenes/Scene_DB/Scenezl_Final 1.unity`。

## 新增内容与位置

Hierarchy 新增独立根节点 `Aerospace_Dragonbone_ResearchDetails_V1`。

| 子节点 | 内容 |
| --- | --- |
| `01_Entry_Research_Sign` | 台阶侧边的“龙骨遗骸观测区 / DB-01”标牌，附简化遗骸示意图 |
| `02_Low_Sampling_Tags` | 四个低矮的编号取样标牌 |
| `03_Fixed_Scanning_Probes_No_AI` | 两个朝向遗骸中心的固定三脚扫描探头，仅有小面积青色自发光 |
| `04_Cable_Branch_0`、`04_Cable_Branch_1` | 两段贴地短线缆和小接线盒，不横穿主要路线 |

这些细节是利用 Unity 几何体制作的原创组合，不是本次从网络下载的新模型。材质、独立中文字体图集和预制体统一存放在 `Assets/Art/Environment/DragonboneResearchDetails_V1`。字体来源为项目原有 `Assets/Font/text-c.ttf`，没有改动小地图共用的中文字体资产。

你移动到外围的 `Aerospace_SetDress_V1` 没有重新摆放。其位置、旋转、非等比缩放和子物件保持不变；原来的龙骨、晶体、宝箱、台阶、敌人出生点及撤离点也没有移动。

## 外侧调查站灯光

为了减轻设备表面的亮斑，仅降低调查站三个原有点光源的强度；当时没有改天空盒、太阳光、全局环境光或昼夜周期（正式场景后续于 2026-09-21 调整为 160 秒）。

| 原有灯光 | 原强度 | 本版强度 |
| --- | --- | --- |
| `Core_CyanLight` | 1800 | 90 |
| `Sensor_CyanLight` | 850 | 55 |
| `Approach_WarmLight` | 700 | 30 |

新根节点上的 `AerospaceResearchLightingOverride` 保存这三个光源的原亮度。隐藏或删除根节点时自动恢复；重新启用时应用本版亮度。隐藏时不会覆盖你在启用期间手动改成其他数值的光源。也可以只禁用这个组件，保留新景观但恢复旧灯光。

## 不影响 AI 行走的措施

新增物件没有 Collider、Rigidbody、NavMeshObstacle、NavMeshAgent 或玩法目标脚本，不新增 AI，也没有实时扫描行为。

所有新增节点使用 `Ignore Raycast` 层，不截获正常物理点击；根节点的 NavMeshModifier 设置 `Ignore From Build` 并覆盖所有子节点和 Agent 类型。实际检查现有 NavMeshSurface 收集的烘焙输入，新物件未进入其中。没有重新烘焙或修改 NavMesh。

摆放时按完整渲染包围范围，避让现有图路线、资源交互点、宝箱的实际模型中心及敌人出生点。路线避让半径为 3.5 米加物件半径，交互点及出生点为 8 米加物件半径。地面高度只读取原有模型与地形，没有改动地形或植被。

生成前后，两名 Agent 的 1512 次导航查询结果、路径转角及导航网格几何完全一致；原有完整路径数为 1308，其余已有非完整路径没有因本次景观产生变化。检查仅验证导航与景观隔离，不替代整局战斗的人工体验。

## 查看、对比与撤回

1. 在 Project 中打开上述正式场景，不要打开名字相近的历史 `Scene_ZL/Scene_Zl_Final.unity`。
2. 在 Hierarchy 搜索 `Aerospace_Dragonbone_ResearchDetails_V1`，选中后按 F 聚焦。清空搜索后可展开查看各子组。
3. 要临时对比原版，取消 Inspector 顶部节点名称左边的复选框。新增细节全部隐藏，调查站局部灯光恢复。重新勾选即可恢复本版。
4. 要撤回本次摆放，可以删除此根节点并保存场景。不要删除原有 `Aerospace_SetDress_V1`，也不需要删天空盒节点。
5. 修改前的完整场景备份在 `UserSettings/SceneBackups/Scenezl_Final 1_Before_Dragonbone_ResearchDetails_V1.unity`。只有需要完整恢复时才使用；完整恢复会同时撤销备份之后其他场景编辑，所以通常优先隐藏或删除新增节点。

真实场景预览存放在 `UserSettings/ScenePreviews/DragonboneResearchDetails_V1`，含入口、整体、探头、夜间及外侧调查站调整前后的图像。预览和备份不提交到 Git。

编辑器菜单 `Tools > Extraction-like > Aerospace > Render Dragonbone Research Details V1` 仅生成预览，不保存预览的夜间光照。`Build Dragonbone Research Details V1` 在已有本版根节点时会拒绝覆盖，避免丢失手动调整。不要重新执行旧的 Dragonbone Layout V1 构建命令，否则会重建你已经移动的旧调查站。

回归测试：`DragonboneResearchSafetyTests` 9 项、`AerospaceInvestigationSafetyTests` 10 项、`MapGraphViewportVisibilityTests` 7 项，共 26 项全部通过；覆盖开关对比、删除恢复、灯光预制体覆盖值保存、中文字体及导航隔离。正式场景序列化标识无重复。测试报告保存在预览目录的 `editmode-tests.xml`。本次未提交或推送 Git。
