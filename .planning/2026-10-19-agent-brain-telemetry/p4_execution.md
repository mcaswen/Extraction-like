# P4 战斗树：执行记录

目标见 [大规划](task_plan.md) 第 4.3 节和第 8 节 P4。

## 1. 旧节点的调用顺序表

`EngageEnemyActionNode` 每帧按下面的顺序执行，新树必须保持同样的顺序和次数：

1. 取智能体，失败则返回失败；取交战指令，没有则返回失败。
2. 命令 ID 变化时清零失视计时、接近点缓存、"已看见目标"和初次接近预算。
3. 解析目标敌人：指令指向的敌人（或其碰撞体子物体）；否则群内最近的存活敌人；否则在目标对象上找敌人组件。
4. 解析不到 → 清"可见敌人"事实、释放指令，返回成功。
5. 敌人已阵亡 → 通报击败 → 清事实、释放指令，返回成功。
6. 通报交战（每帧一次）。
7. 读攻击距离、移动速度；查身体到目标的视线（纯射线）。
8. 取射手；缺射手或未配置 → 以"攻击不可用"结束指令，返回成功。
9. 枪口和弹道检查（会覆盖射手的"上次射击结果"）；能否开火 = 视线可见且枪口通畅。
10. **不能开火**：读"可见敌人"事实和上次射击是否被挡 → 更新"已看见目标" → 判定是否为"玩家手动且尚未看见" → 看得见且没被挡就清零失视计时，否则（非手动初次接近时）开始计时 → 取失视时限。
    1. 失视超时 → 以"失去视野"结束指令，返回成功。
    2. 导航未就绪 → 作废接近点缓存，直奔敌人地表点，返回运行中。
    3. 需要时重求接近点；求不出 → 以"不可达"结束指令，返回成功。
    4. 玩家手动初次接近：第一次时按初次路径算预算（路径不可达 → "不可达"）；预算耗尽 → "失去视野"。
    5. 移向接近点，返回运行中。
11. **能开火**：清零失视计时、记为已看见、停步 → 攻击冷却中则返回运行中 → 有就绪技能则释放、播放动作、锁定攻击，击杀则收尾返回成功，否则运行中 → 否则普通射击：失败时若是弹药不可用则以"攻击不可用"结束指令，返回运行中；命中则播放动作、锁定攻击间隔，击杀则收尾返回成功，否则运行中。

进入节点时（树每次重启、状态重新进入）重置失视计时、接近点缓存时间、"已看见目标"和初次接近预算，命令 ID 保留。

## 2. 新树

```
交战记忆（作用域：进入时重置计时，命令 ID 保留）
└─ 交战（响应式序列）
   ├─ 条件  智能体可行动
   ├─ 条件  持有交战指令
   ├─ 动作  同步交战命令
   ├─ 动作  解析目标敌人
   └─ 处置（响应式选择器）
      ├─ 目标已结束：条件 目标丢失或已阵亡 → 动作 收尾战斗
      └─ 交战中（响应式序列）
         ├─ 动作  通报交战
         ├─ 动作  评估射界（视线 → 射手 → 枪口）
         └─ 应对（响应式选择器）
            ├─ 攻击不可用：条件 射手不可用 → 动作 判定攻击不可用
            ├─ 开火：条件 可开火 → 动作 停步瞄准 → 出手（响应式选择器）
            │   ├─ 冷却：条件 攻击冷却中 → 动作 等待冷却
            │   ├─ 动作  释放就绪技能（没有可放的技能时失败）
            │   └─ 动作  普通射击
            └─ 接近：动作 更新失视计时 → 接近决策（响应式选择器）
                ├─ 失去视野：条件 失视超时 → 动作 判定失去视野
                ├─ 直接靠近：条件 导航未就绪 → 动作 直奔敌人
                └─ 求点并移动：动作 求接近点 → 动作 检查初次接近预算 → 接近结果（响应式选择器）
                    ├─ 不可达：条件 求不出接近点 → 动作 判定不可达
                    ├─ 初次路径不可达：条件 初次路径不可达 → 动作 判定不可达
                    ├─ 预算耗尽：条件 接近预算耗尽 → 动作 判定失去视野
                    └─ 动作  移向接近点
```

**"结束指令并返回成功"的终止分支**：旧节点里的每一处"结束指令、返回成功"都对应一个"条件 + 判定"的分支，判定动作返回成功，经响应式选择器和序列一路传到根，根结果与旧节点一致。

**带副作用的查询放进评估动作**：视线、枪口检查、接近点求解、初次路径预算都在"评估射界""求接近点""检查初次接近预算"这类动作里执行，结果写进交战记忆；条件节点只读记忆。这样每帧调用次数和位置与旧节点相同，枪口检查只调一次。

**执行记忆**：`AgentEngageMemory` 同时实现作用域接口。跨帧字段与旧节点字段一一对应；帧内字段（目标敌人、射手、能否开火、观察结果、失视时限、接近与预算结果）由评估动作每帧重新写入。

**中断**：新节点都没有中断副作用（旧节点也没有），优先级切换时被中断的分支不产生调用。
