# G2 固定摆放线路和有限微调

范围：复用冻结导航矩阵，生成横竖单段线路；固定模式不改变任何位置，微调只产生待接受的候选。

文件归属：MapGraphPlacementConnectionPlanner.cs 独立负责算法，复用 MapGraphConnectionCandidates、GridPlacement 和原几何/意图/导航校验。GenerationController 增加固定连线、局部建议和草稿校验模式；Document 提供草稿输入和网格参数，不承担候选搜索。没有 Runtime 接口或数据结构变化。

固定模式先保留人工/带样式边，再按实际导航长度选择同行同列的合法边，避免重复端口和障碍，尽量补全各允许连接分量。每次边验证为一个可中断工作项。缺失横竖通路时明确报告断开的节点，不发布半图。

微调使用有限候选搜索：以初始摆放为位移基准，单坐标最大位移为指定格数（默认 1 格，UI 上限 4 格），节点锁、区域锁和行列锁均保留。有限宽度候选队列优先减少断连，其次减少总位移；每个邻居仍走相同固定线路算法。预算耗尽或未发现更好候选，只报告“预算内未找到”，不声称数学无解。计算过程中不查询 NavMesh，生成前的扫描由既有控制器负责。

独立验收：最终完整几何、全部人工意图、各 profile 可达分量均再验；取消、身份变化或版本变化不得接受候选。草稿校验保留手画拓扑，不隐式生成新线。原已发布地图的旧编辑 API 保持兼容。

测试：固定零位移、导航岛、禁连、人工样式、端口/名称障碍、对角固定失败、微调上限和锁、预算及取消。补充真实 NavMesh 文档用例验证候选接受、Undo、保存证据和过期拒绝。

实现与验证：G2 完成。线路构造 8/8 PASS（Logs/AgentReproduction/20260913-180203-362），作者文档 12/12 PASS（Logs/AgentReproduction/20260913-180344-801），其中新增真实 NavMesh 草稿应用/Undo 和候选过期验证，覆盖原工作图行为。

审查：候选搜索保存在独立规划器，生成控制器只编排，数据流没有进入 Runtime。固定模式和建议共用 Evaluate 及最终独立校验。交互建议队列宽度 8，布局预算最多 512，可由已有配置进一步降低；每次边验收让出执行，取消丢弃候选。保留无成员锁定行列，避免规范化时意外删除原作者约束。算法为有限启发式，预算内失败不是数学无解。
