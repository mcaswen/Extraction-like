# G3 画布选点和发布流程

范围：把用户确认的操作落到正式 Editor 窗口，完成截图、保存重开和说明。

文件边界：新增 MapGraphConnectionSelection.cs，只保存临时起点、终点、显式重绑和版本；Canvas 输入映射到该状态，发出一次请求。Document 复用 AddEdge/RebindEdge 和冻结导航证据进行校验，成功才写草稿；Window 编排首次证据刷新，不把导航查询放入 Shift 事件。Inspector 移除连线下拉框和方向框，保留只读端点、重选端点和样式。已有 UnityEditorViewCapture 负责捕获真实窗口，不另外模拟绘图。

连线失败保留双选和旧图，第三次 Shift 替换终点；明确点击“重选端点”才改旧边。Esc、空白、版本和身份失效清理临时态。恢复后缺少导航证据时可以只校验已发布工作图获取证据，不能以此覆盖尚未生成的摆放草稿。画布展示网格和行列辅助线，候选显示原位置到新位置的差异，顶部标明当前工程/场景。

测试：独立选择状态机，文档连线拒绝/保留以及删除后重连，真实窗口 SendEvent 驱动鼠标事件并截图，使用测试拥有的场景/NavMesh 完成摆放→线路→保存→重载。所有测试无需用户操作，不改用户场景。

实现与验证：真实窗口最终 6/6 PASS（Logs/AgentReproduction/20260913-182834-300）。自动 SendEvent 完成拖动、失败双选、Esc、微调接受、删除后 Shift 重连、样式编辑、发布和重开；测试拥有独立场景、NavMesh 资产和 3 个群。正式场景仅做窗口外观读取，未保存用户场景。6 张真实窗口 PNG 已逐张打开检查，网格和区块保持深色风格，起终点双色高亮，侧栏已经没有连线下拉列表。

Review 后补充：微调候选按位移排序，优先尝试只移动一个轴；预览增加金色位置变化参考的图例。窗口新增“暂存关闭”，通过按工程路径、场景路径隔离的 Unity SessionState 恢复未连通草稿，编译恢复仍使用序列化字段；显式放弃时清除恢复记录。自动用例真实关闭并重建窗口验证草稿保持。SessionState 保证同一次 Editor 会话内重开，不宣称断电/Editor 崩溃后的持久恢复。

最终定向回归 38/38 PASS：网格 5、线路 9、选择 4、文档 14、真实窗口 6。原始报告、NUnit XML、成本事件和截图哈希已归档 outputs/map-grid-authoring/evidence。

最终 Review 发现初次打开窗口的后台导航补证据仍会暂时禁用拖动，已将它从摆放前提中移除：可以直接拖群，提交摆放时取消过期扫描；主动提交连线的导航核对仍需完成。同步删除窗口已不用的旧即时求解编排，Document 旧 API 保持兼容。真实窗口用例增加“扫描中仍可摆放”断言。
