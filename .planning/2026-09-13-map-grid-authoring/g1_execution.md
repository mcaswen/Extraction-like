# G1 网格摆放草稿

用户已以“ok，开始实现吧”确认整体方案。目标：拖动只移动选中群，区域整体平移成员，草稿允许暂时失效，不能写入运行时图。

文件边界：新增 MapGraphPlacementState.cs 保存 Editor 专用隐藏 ScriptableObject 状态；新增 MapGraphGridPlacement.cs 负责纯吸附、坐标移动和行列规范化。MapGraphEditorDocument.cs 复用原工作 SO，新增 AuthoringLayout 作为编辑视图，Layout 仍表示已验证工作图。Canvas 只提交最终落点，一次拖动对应一次 Undo；拖动中仅画预览，不进入求解或导航。

网格采用全图原点，最近格点吸附，半格沿远离零的方向处理。手工移动不会隐式固定节点；固定开关只约束后续算法。行列按当前坐标重建，保留未改变的约束身份和显式锁；手动离开锁定行列视为该节点的明确位置编辑，不连带移动其他成员。区域平移采用格点位移保持成员相对关系，缩放保持成员绝对位置。

草稿和工作 SO 同组 Undo，编译/窗口恢复分别序列化；草稿一旦改变，取消旧生成任务并提升版本。发布必须先应用有效候选，源资产始终保持原内容。测试覆盖负坐标、独立移动、区域移动/缩放、原图隔离、真实 Unity Undo/Redo、恢复及发布门控；只在隔离 Regression 副本运行。

实现与验证：G1 已完成，5/5 PASS（Logs/AgentReproduction/20260913-175605-924/report.md）。首轮仅测试代码误用了不存在的 Enemy 枚举，已改为有效构造类型后重新运行，正式实现没有编译错误。

审查：Editor 草稿独立于工作 SO 和 Runtime；节点拖动只在释放时提交一次，拖动中无导航和求解。坐标操作复杂度主要为节点/对齐表重建 O(N²)，本轮不引入缓存或全局状态。图身份不可被位置操作替换，失效边沿用原绘制判断而不显示斜线。Undo/Redo 同时记录两个隐藏对象，恢复后仍要求新导航证据。G2 将补全草稿候选校验，G3 替换旧连线列表入口。
