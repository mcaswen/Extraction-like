## 4. 性能、缓存与画面

MR04 使用 NVIDIA GeForce RTX 5090 D、Direct3D11、URP High Fidelity、3840×2160、Development Player，1×、vSync=0、不限帧、每帧真实渲染，未开启 Profiler。217.34 秒墙钟内采集 37336 个帧样本、37335 个有效间隔和实际渲染帧，**全量平均 172.934 FPS**，p99=8.7224 ms、1% low=80.90 FPS、最低一秒 94 FPS。包含启动及诊断/截图开销，没有剔除慢帧。验收门槛仅平均 >60；4× Editor 均帧和尾部指标不替代该门槛。

实际 Play Mode/Player 全部由 Agent 运行，测试代理只操作正式背包。终局合同覆盖两人真实移动、搜刮转移、交战伤害、暂停恢复、容量撤离和反击恢复，库存账本与最终仓库逐项一致；0 运行异常、0 停滞疑点、0 丢事件，61 条警告保留。路线合同通过 816 次路线帧、1455 次同步显示、709 次线上行进样本。小/M 图有限切换两次，展开状态采样 114 次，根身份保持，新增 UI 指令 0。

**原始报告没有被改成通过。** 它将一次 `MoveTo:NoProgress` 记为 FAIL：事件 737 的旧子指令，在 739/741 以同根版本 4→5 重规划，774 实际 Completed；接受间隔 0.0272 秒、完成耗时 3.0820 秒、实际平面位移 6.9493 米。该行为符合已有有限重规划设计。报告新增严格恢复证明后，原始失败数仍为 1、已恢复数 1、未恢复数 0，完整帧/结算/路线/视口合同重新计算通过。多次失败、改根、缺完成、取消/战死或无真实位移均不豁免。

## 5. 使用入口和边界

- 游戏：直接打开 Scenezl_Final 1，Tab 切焦点，点世界／地图上的群下令，M 展开同一地图。正式资源交互仍由玩家操作背包；只有测试驱动自动处理背包。
- 作者工具：`Tools/Anomaly Search/地图指挥编辑器`。显示编辑不移动世界；连线改变可规划拓扑，重新生成保留人工锁定/禁连。图约束无解时明确拒绝，不产生折线或假可达边。
- 当前菜单仍进入 Scene_lyl_test2 1，没有把此次场景安装扩大为全项目场景迁移。
- 验收输入为当前工作区的实际场景，包含用户已有且尚未提交的场景/NavMesh 修改。本轮只提交自己的精确场景增量，不将其余用户编辑一并纳入提交；输入清单和哈希由每轮运行器保存。
- 原生 NavMesh、动态敌人和物理模拟会影响具体战斗结果；本报告说明固定构造及记录的场景覆盖，不承诺任意关卡配置或任意种子均无问题。
- 高处导航恢复 1× 的首帧丢失已定位到旧物理 bounds 并修复，原单帧测试和固定窗口对照均保留，完整组 14/14 通过；历史失败不删除。
- 当前 Agent 普攻 Prefab 为球形，净空预测支持其尺寸；未来改为非球形弹体时须相应扩展，不能把此次验证当成任意弹体形状支持。
