2026-09-13。G7 报告中的两项问题已修复：龙骨礁群可以继续处理，当前发布图可以零补算加载导航缓存。最终 **12 项定向测试通过，另有 1 项隔离缓存维护通过**；两轮 4× 实际场景的路线合同、终局合同通过。自主轮保留一次已恢复的 LostSight 原始诊断，不宣称零告警。

## 1. 龙骨礁阻塞的根因和修复

失败探针定位到 `Zone-龙骨礁/tripo_convert_cfc50981-c500-4787-94ae-f41149c942c9/Torus/Range`。其 BoxCollider 世界尺寸约 **151.38 × 0.52 × 183.54 m**，同时包围群内 TidalAberration 和 AncientStrander 的瞄准点。两个敌人的导航路径完整，但实体碰撞盒阻挡射线，正式候选扫描和独立扩大取样均不能找到合法射击位置。证据见 [逐敌人诊断](review/processing-probe.json)。

该 Range 对象只有 Transform、BoxCollider，没有渲染或行为组件，也没有其他场景序列化引用；父 Torus 已有真实 MeshCollider。修复仅将场景 **BoxCollider `fileID:959548491` 的 `m_Enabled` 从 1 改为 0**，保留对象、坐标、Prefab、群和父模型碰撞。

真实场景定点反例使用 Agent 的实际缩放和 baseOffset。重新启用辅助盒时两个敌人均为 Unreachable，关闭后两个敌人的正式校验均为 None，群 Resolver 可以创建处理指令。修复前保存态断言失败，修复后通过。没有修改候选扫描、交战射线、攻击范围、重试次数或清整群规则。

## 2. 导航指纹稳定性和缓存

构造用例证明：同一组 NavMeshData 仅改变注册顺序，旧指纹就从 `22096c…` 变为 `15d52a…`。这确认了旧实现对原生枚举顺序敏感；G7 历史发布会话没有保留全部原生数组，不能进一步声称已还原那次会话的全部差异。

`MapGraphNavigationGeometrySignature.cs` 现在规范顶点/三角形顺序，同时保留精确坐标、区域、绕序、重复数量和原始顶点共享关系。同坐标顶点通过有向邻接面的内容区分，仍有歧义时保留原相对序，保守失效；不合并顶点，不量化坐标。非法数据返回空签名。`MapGraphNavigationFingerprint.cs` 继续组合 Surface、Link 配置，活动链接仍须补验；profile、锚点和真实几何变化继续使旧成本失效。

当前发布资产 revision **5 → 7**，只更新版本和导航证据，所有地图布局、节点、连接、人工约束及设置相等。缓存维护复用既有 CostService，对保存绑定的 26 条边测量，未重新选择导航锚点。第一次 ValidateOnly 的隔离产物因锚点变化被导入保护拦下，没有写入主项目。

最终保存、安装、重新采集的指纹均为 `bf5f5c4322e4fedb54c007895bc885c76e580fd97d87889392f6f23e20123636`；两名 Agent **pending=0，installedQueries=0**。见 [正式缓存证据](final-runtime-cache/runtime-cache.json)。旧版资产仍通过原预算补算兼容，当前资产已刷新。

## 4. 性能、文件边界和资产保护

签名使用连续邻接缓冲，额外工作约 O((V+T) log(V+T))，空间 O(V+T)，沿用启动/导航变更时的采集入口。实际场景为 33,909 个顶点、15,473 个三角形，本次一次完整 Capture 约 **56.83 ms**，包括原生采集、排序、场景签名和哈希，不是每帧开销。零补算只证明移除了额外连接查询，不据此宣称整体启动耗时已经更短。

4× Editor 的诊断均帧：SC02 约 **90.67 FPS**，SC10 约 **69.74 FPS**，均包含启动；存在启动长帧，且部分验证并行运行。这些数据不是新的 1× Player 性能验收。

生产改动归属纯几何签名、原指纹组合和一处场景配置；路线、敌人生成和战斗所有权保持。新增失败探针仅在 `UNITY_EDITOR || ANOMALY_SCENE_AUTOMATION` 下编译，运行验证时每个 Agent/群最多一次、每次运行最多 8 组，普通帧不增加路径查询。

程序已与 `48bbaa3` 对照：场景除已确认碰撞盒 enabled 外全部内容相等；地图除版本和缓存外全部配置相等，见 [范围审查](review/map-fix-scope-review.json)。最终用例的相关代码、资产哈希一致，缓存纯构造用例使用相同最终代码，资产刷新单列。原始失败、审查中间态、成功结果及输入清单保留在 [manifest.json](manifest.json)、[run-summary.json](run-summary.json)，压缩证据解压后与原件逐字节相同。

所有验证由 agent 执行，使用 Regression 和 MapValidation 独立工作区，测试驱动代操作背包。保留场景验证 Editor，未覆盖用户 Final 副本或关闭用户 Editor。
