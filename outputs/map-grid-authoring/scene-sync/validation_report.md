# 地图编辑器场景同步验收

2026-09-13。实现和架构审查完成，42 项定向测试全部通过。

## 根因和修复

原编辑器能检测场景身份差异，但没有将删除、换区等变化合并进地图草稿的入口。生成器仍以旧节点和区域归属校验，因此重复生成继续出现 NodeSynchronizationRequired、LayoutOnlyCannotSynchronizeTopology、SceneSynchronizationRequired。用户本次明确这些变化是有意的场景编辑，已补齐实际同步流程。

打开窗口、场景层级或保存发生变化、生成/微调/校验前自动同步，也可点击“同步场景”。“同步记录”逐项显示新增、删除、换区和关联线清理。场景拥有群身份和归属，地图保留手工布局与样式：移除缺失群及失去端点的线/禁连，其余人工数据保持；换区群映射到新区域内的相对位置，新增群按世界相对位置落点。

同步只进入独立草稿，支持 Undo 和编译恢复。当前草稿可独立补充导航证据以继续 Shift 连线，导航证据不能代替几何校验或直接发布。场景事件采用 0.3 秒去抖，不增加逐帧全场景扫描。
