# 原连接不可见却报重复的修复验收

2026-09-13。实现和架构审查完成，41 项相关回归全部通过。

## 根因和用户截图对应

正式地图中的龙骨礁 `EnemySourceCluster_A`（cluster_73607cab556336476bac9995b5e46c2b）与 `ExtractionCluster`（cluster_a84fd1c0b6b5590d95cbf011798b2e2a）已有连接 `edge_cb16fe6e2d6138de2adb3f829b774c69`，旧方向为水平。

移动群时旧连接保留，但没有跟随作者落点自动改 Axis。垂直摆放后，严格线段计算返回 false，Canvas 不绘制也不能命中；新增连接判重仍发现原边，只报 ConnectionAlreadyExists。构造直接使用正式资产中的两个节点验证这条链路，源图没有被改写。修复前运行 20260913-202941-860 的 1/1 是确认缺陷条件的通过记录，不是修复结果。

## 修复行为

- 普通 Shift 选中两群已有的连接，显示可读原因，不增加重复边或导航扫描。
- 旧方向失配、留白过大、颜色接近透明时，Editor 提供可点击的横竖警示表示；绘制、命中及诊断高亮共用同一只读结果。
- 面板显示待修正数量和具体原因，方向失配可点“按当前对齐修正方向”。该操作只改 Axis，保留边身份、端点、来源、长度、留白、线宽和颜色，支持 Undo/Redo。
- 对角或图标重叠时不画斜线/折线，仍可 Shift 选两端查看原连接、重选端点或删除。

警示表示只存在于编辑器，严格几何和正式发布门控不变。不会自动删除原边，也不会发布用户当前草稿；修正后按正常流程校验、应用预览和发布。
