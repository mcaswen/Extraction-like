# 允许地图连线穿过区域名称框

2026-09-13。实现、65 项定向回归和架构审查完成。

## 当前行为

横竖连接允许穿过区域名称框。手动 Shift 连线、固定位置生成、微调、布局求解、补线和发布复用同一规则，不再报 EdgeThroughName。群图标仍须避让名称，连线仍须避让其他群图标，横竖、端口、留白及导航检查保持。

编辑器中的区域名称在线条之后绘制，底部明确“群图标避让名称框，连线可穿过”。本次不移动用户群或区域，不重写正式图，不发布用户的当前草稿。

真实窗口构造场景同步后的两群，Shift 添加跨区域横线，程序确认实际线段与名称框相交。经导航补证据、生成、保存、关闭并重开场景后，核对同一连接 ID、Binding 以及相交关系。用户无需操作或运行 Play Mode，全部在独立 Regression 项目执行。

首次窗口运行 20260913-211510-994 在异步导航完成前断言失败；第二次 20260913-211734-464 的嵌套测试枚举器延迟读取了已经完成并被消费的任务。最终测试直接限时等待草稿中出现连接，9/9 通过。仅修改测试时序，生产实现未再变化；其他五组各自用例、生产源码及目录哈希与最终内容一致。两次失败 XML 保留于 evidence，未计入最终通过数。

## 架构和成本

删除 Validation 的 O(E×Z) 线/名称检查，删除布局每次迭代中只供名称避让的 O(E) 临时线段数组。ZoneLayout 只计算矩形包含和图标避让，中心候选仍有界。没有新的运行时开销，本轮不重新测量或宣称 FPS。

没有新增生产文件、持久化结构或反向依赖；运行时已有绘制路径可直接使用通过发布校验的连接。场景和正式地图资产在各次运行中的哈希一致。源码与各组用例的核对范围、事件、XML 见 [证据清单](evidence/manifest.json)，文件归属审查见 [G6 架构审查](../../../.planning/2026-09-13-map-grid-authoring/architecture_review.md)。
